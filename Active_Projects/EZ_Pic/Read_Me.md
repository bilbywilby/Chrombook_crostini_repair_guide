 # EZ_PIC: Photo Organizer and Processor

## Overview
EZ_PIC is a user-friendly application designed to organize and process images efficiently. It provides a simple graphical user interface (GUI) that allows users to select a folder of images, choose processing options, and initiate the processing with a single click. The application takes care of resizing, enhancing, and applying filters to the images, saving the processed images in a specified output folder.

## Key Features
- **Folder Selection**: Users can easily select a folder containing the images they want to process.
- **Resize and Enhance Options**: The application provides options to resize and enhance the images.
- **Multi-threaded Processing**: EZ_PIC utilizes multi-threading to process images in batches, significantly reducing the processing time for large collections of images.
- **Progress Tracking**: A progress bar and status label keep users informed about the progress of the image processing.

## Installation and Usage
To use EZ_PIC, follow these steps:

1. **Clone the Repository**: Clone the EZ_PIC repository from GitHub.

```
git clone https://github.com/username/EZ_PIC.git
```

2. **Install Dependencies**: Install the required Python libraries using the `pip` package manager.

```
pip install -r requirements.txt
```

3. **Run the Application**: Navigate to the EZ_PIC directory and run the main script.

```
python EZ_PIC.py
```

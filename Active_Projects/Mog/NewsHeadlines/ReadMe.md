# Headline Scraper

This is a python script that scrapes the headlines from a news website and saves them in a file.

## Requirements

- Python 3.x
- Requests
- BeautifulSoup
- Tkinter

## Usage

- Run the script using `python headline_scraper.py`
- Choose a news website from the list of options
- Choose a file format to save the headlines
- Choose an encoding to save the headlines
- Choose a file name and location to save the headlines
- Wait for the scraping process to finish
- Check the file for the scraped headlines

## Features

- Scrapes headlines from CNN, BBC, NYT, and FOX
- Saves headlines in text, csv, or json format
- Supports different encodings such as utf-8, ascii, iso-8859-1, and windows-1252
- Provides a user interface with tkinter
- Shows the progress of the scraping process

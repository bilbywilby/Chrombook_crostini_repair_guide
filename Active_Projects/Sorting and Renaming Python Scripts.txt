Here is an example Python script that can automate the process of creating a Python file with some initial code in it, using the `argparse` library to parse user input for the filename and initial code:

```
import argparse

def create_file(filename, initial_code):
    """
    Creates a new Python file with the given filename and initial code in it.
    """
    with open(filename, 'w') as file:
        file.write(initial_code)

if __name__ == '__main__':
    # Parse user input for filename and initial code
    parser = argparse.ArgumentParser(description='Create a new Python file')
    parser.add_argument('filename', help='the name of the new Python file')
    parser.add_argument('--initial-code', help='initial code to put in the new file', default='')
    args = parser.parse_args()

    # Create the new file with the given filename and initial code
    create_file(args.filename, args.initial_code)

    print(f'Successfully created {args.filename} with initial code:\n{args.initial_code}')
```

You can run this script from the command line with `python create_file.py name_of_file.py --initial-code "print('Hello, world!')"`, where `name_of_file.py` is the name of the file you want to create, and `"print('Hello, world!')"` is the initial code you want to put in the file. 

This script will create a new Python file with the given filename, and write the initial code (or an empty string if no initial code is provided) to the file. It will also print a message indicating that the file was successfully created and the initial code that was written to the file.

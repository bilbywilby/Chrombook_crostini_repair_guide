 # File Organizer and Renamer Tool

This tool helps you organize and rename text files in a directory and its subdirectories. It provides options to remove metadata from files, rename files randomly, and organize files by extension into folders.

## Installation

To install the tool, simply clone this repository:

```
git clone https://github.com/username/file-organizer-renamer
```

## Usage

To use the tool, navigate to the cloned repository and run the following command:

```
python Ez_File.py <directory_path> [options]
```

where `<directory_path>` is the path to the directory you want to organize and rename files in.

The following options are available:

* `-r`, `--remove-metadata`: Remove metadata from files.
* `-n`, `--random-rename`: Rename files randomly.
* `-o`, `--organize-folders`: Organize files by extension into folders.

## Example

To organize and rename text files in the `Documents` directory, you would run the following command:

```
python Ez_File.py Documents
```

This will organize and rename all text files in the `Documents` directory and its subdirectories. If you want to remove metadata from files, you would use the `-r` or `--remove-metadata` option:

```
python Ez_File.py Documents -r
```

If you want to rename files randomly, you would use the `-n` or `--random-rename` option:

```
python Ez_File.py Documents -n
```

If you want to organize files by extension into folders, you would use the `-o` or `--organize-folders` option:

```
python Ez_File.py Documents -o
```

## How it Works

The tool works by first generating a list of all text files in the specified directory and its subdirectories. It then iterates through each file and performs the specified operations.

If the `-r` or `--remove-metadata` option is specified, the tool will remove metadata from the file. This is done by opening the file in binary mode and overwriting the first 1024 bytes with zeros.

If the `-n` or `--random-rename` option is specified, the tool will generate a random filename for the file. This is done by generating a 10-character string
